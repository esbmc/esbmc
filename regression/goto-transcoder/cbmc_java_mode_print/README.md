Symbols in a goto binary carry the mode of the language that produced them, and
a jbmc-produced binary spells that `java` -- a language ESBMC has no frontend
for. Printing an expression belonging to one (here `--goto-functions-only`, but
equally `--show-vcc` or a counterexample) used to build a null `languaget` and
abort. Regenerate with `gen_cbmc_java_mode_print.py` (needs `symtab2gb`).
